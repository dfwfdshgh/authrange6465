# authrange6465     【课程公告｜授权靶场练习说明】
最新通知，程序新添加功能，反调试跟反沙箱，只要解包，就会出现错误的程序，表现为exe挂解包出来的是另一个程序，然后卡密是错误的，但是如果是正常就是双击运行exe，但是只要双击就会自动删除文件，哪怕不输入卡密也是一样的。卡密是正确的，只有双击exe文件，输入卡密，才能正常运行程序。     同学们，统一说明一下：仓库里这些程序都是课程用的授权靶场样本，不是外面的真实商业软件，已经获得授权，只用于教学、分析和防御练习。你的课程目标不是去逆源码，也不是去搞正版软件，而是在这个靶场环境里，把卡密校验流程绕过去，让程序能正常进入、正常使用。能做到这一点，就算课程完成。

这个靶场有反调试，也上了 VMP，源码基本不用想还原，别一上来就死磕逆向。外面有人说“直接买正版吧，或者别想着逆向了”，我理解，但咱们这是授权靶场，方向不是还原代码，而是动态处理：先搞定反调试，观察随机数、时间戳、nonce 这类东西，抓一次成功登录的返回包，然后自己架本地服务器模拟返回，或者 patch 内存，过掉登录判断。

注意，重放包不是万能的，通常只对心跳包有用，登录包大概率有时效、签名或随机数校验。卡密可以找我要测试卡密。你们先自己试抓包、调试、内存修改；实在不成功再来找我要卡密。不要去买正版，也不要在任何未授权软件上试。
